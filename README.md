# Hasibul Islam Portfolio

Professional portfolio website for software job applications and funded PhD outreach.

Live site: https://sifathasib.github.io

Portfolio intake form: https://sifathasib.github.io/intake.html

The intake form stores draft data in the browser, can preview that data on the portfolio page, and exports `portfolio-data.json` for future published updates.

To publish updated content, export `portfolio-data.json`, replace `data/portfolio-data.json`, add final assets such as profile photo/CV files, and commit the updated data/assets to GitHub Pages.
